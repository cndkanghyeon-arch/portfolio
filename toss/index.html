셀러가 2만에서 8만으로 늘었고, 다음 목표는 50만입니다

확인한 사실

  • 2025년 5월 공동구매에서 오픈마켓으로 전환
  • 입점 셀러가 1년 만에 3배 가까이 증가, GMV는 전년 대비 약 80% 성장
  • 빠른 정산과 수수료 혜택, 성과형 광고가 셀러 유입의 축
  • 기본 판매 수수료 8%, CPC 광고 유입 주문은 조건부 수수료 면제

그래서 생기는 문제와 제 접점

  • 셀러가 늘수록 개별 대응으로는 감당이 안 됩니다. 반복 요청을 기능으로 구조화해 고객사 개발 요청을 80% 줄인 경험이 있습니다
  • 빠른 정산은 정산이 틀리지 않아야 성립합니다. 정산 오류 50% 감소, 중복 결제 100% 제거를 만든 일이 제 주력입니다
  • 수수료와 광고가 얽힌 구조는 수익 모델 설계 문제입니다. 수수료 기반 제휴 모델을 0에서 1로 만들어 월 8,000만 원을 냈습니다
  • 금융과 쇼핑의 연결은 결제 흐름 설계입니다. 앱 안에서 가입과 결제가 끝나는 채널을 신설해 매출 약 30%를 올렸습니다

커머스 운영, 동시 다발 과제

광동상회, SPC GFS, 제주삼다수 / ㈜씨앤디팩토리 / PM과 PL

문제 정의
  • 고객사 3곳을 동시에 맡으면서 같은 유형의 요청이 반복해서 들어옴
  • 요청 하나하나를 개발로 넘기다 보니 개발 일정이 운영에 끌려다니는 구조
  • 요청량이 늘수록 응답이 늦어지고 고객사 불만이 쌓이는 악순환
전략 설계
  • 3개월 치 요청을 유형별로 분류해 빈도와 처리 시간을 집계
  • 반복 상위 유형을 고객사가 직접 처리할 수 있는 Admin 기능으로 전환하기로 결정
  • 개발 요청 건수를 핵심 지표로 정하고 전후를 비교하기로 사전 합의
실행과 결과
  • Admin 기능을 순차 배포하고 고객사 담당자에게 사용법을 직접 안내
  • 동시에 ISMS-P 심사 일정과 개발 일정을 하나의 흐름으로 통합 관리
고객사 개발 요청 약 80% 감소ISMS-P 3건 통과
