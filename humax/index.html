Step 01

산출물로 범위를 확정한다

무엇을 언제까지가 아니라 어떤 문서와 화면을 언제까지로 바꿉니다. 화면기획서와 정책정의서, IA, ERD, API 명세를 직접 쓰면서 범위를 고정했습니다.

Step 02

진척을 사람이 보고하지 않게 만든다

주간 보고로 받는 진척은 늦고 부정확합니다. 협업툴 로그에서 지연과 누락이 자동으로 드러나게 바꾸고, 산정식과 데이터 출처를 공개해 합의했습니다.

Step 03

검증 단계를 빼지 않고 닫는다

오픈은 중간 지점입니다. 자동 판정은 1년 이상 운영하며 사람 개입률 0.25%를 확인하고, 연동은 환경별 검증까지 끝낸 뒤에 종료로 적었습니다.

  • 정산은 40개가 넘는 칼럼의 계산 로직을 전수 조사해 기준과 예외를 분리하고 정책으로 재정의
